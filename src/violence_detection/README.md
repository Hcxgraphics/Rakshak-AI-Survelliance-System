This is violence detection system 

Link to original video dataset without preprocessed  : https://drive.google.com/file/d/1y-3qaM2TC2cJreniG7T5XIfSpVIfNBVT/view?usp=sharing

after downloading  run frame extract file is for extracting the frames from each video and saved it to preprocessed folder 

after that , just run model.py file to train the model and detect.py to check it 

details about dataset : 
The dataset contains 1000 videos of each class i.e. Violence and Non-Violence 

after preprocessed and frames extracting we get around 1,27,529 Images(frames) for Non-Violence and 1,59,750 Images (frames) for Violence
